# Baseline Markdown Sample

A **markdown** fixture for the docs/preview path. It covers the common block types so the
rendered-markdown preview has real structure to show.

## Features

- Headings (h1/h2)
- **Bold** and *italic* text
- A fenced code block
- A small table

## Example

```python
def greet(name):
    return f"Hello, {name}!"
```
