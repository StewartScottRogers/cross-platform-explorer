# `samples/crypto/` — JWT + certificate fixtures (CPE-1425)

Real, valid crypto artifacts you can open **in the app** to exercise the JWT-decode (CPE-1418) and
certificate-decode (CPE-1419) features under the Crypto epic (CPE-1417). Every file was generated by a
throwaway Rust program (see "Regenerate" below) — no `openssl` required, no manually hand-edited bytes,
nothing committed to the repo as a permanent build dependency.

Treat this folder like the rest of `samples/` (see [`../README.md`](../README.md)): pristine, read-only
fixtures for manual/GUI checks and automated tests.

## ⚠️ Demo keys only

**Every `.key` file in this folder is a throwaway demo private key and the JWT signing secret is a
throwaway demo string, both committed in the open. DEMO ONLY — do not use in production, and never treat
anything in this folder as a real credential.**

## Files

| File | What it is | Demonstrates |
|------|-----------|---------------|
| `hs256-valid.jwt` | HS256 JWT, rich but ordinary claims (`sub`/`name`/`iss`/`aud`/`iat`/`exp`), `exp` far in the future (2033) | Decode + signature-valid path |
| `expired.jwt` | Same shape, `iat`/`exp` both in the past (Sept 2020) | Expired-token handling |
| `alg-none.jwt` | Header `{"alg":"none","typ":"JWT"}`, empty signature segment (`header.payload.`) | The `alg:none` unsecured-token edge case / vulnerability demo |
| `rich-claims.jwt` | HS256 JWT with an array `aud`, nested `profile.notifications` object, `roles`/`permissions`/`tags` arrays, custom namespaced claims (`https://cpe.local/claims/...`), booleans, a float, and a `null` | Rendering of every JSON claim shape a real-world JWT can carry |
| `self-signed-rsa.pem` | Self-signed RSA-2048 certificate, CN + 2 DNS SANs, valid 2026-01-01 → 2027-01-01 | Certificate decode / create |
| `self-signed-rsa.key` | **DEMO ONLY — throwaway key, do not use in production.** PKCS#8 PEM private key for `self-signed-rsa.pem` | Private-key pairing with a cert |
| `self-signed-ec.pem` | Self-signed EC (P-256) certificate, CN `sample-ec.cpe.local`, valid 2026-01-01 → 2027-01-01 | Non-RSA algorithm decode |
| `chain.pem` | Leaf (`chain-leaf.cpe.local`) + Intermediate CA + Root CA certificates concatenated, each properly signed by its parent | Certificate-chain validation |
| `cert.der` | The `self-signed-rsa.pem` certificate re-encoded as raw DER (no PEM armor) | Binary/DER decode path (not just PEM text) |
| `expired.pem` | Self-signed EC certificate, validity 2020-01-01 → 2021-01-01 | Expired-certificate handling |
| `request.csr` | PKCS#10 certificate signing request (CN `csr.sample.cpe.local`), PEM-armored | CSR decode / "what would this become if signed" |
| `public-key.pem` | The SubjectPublicKeyInfo (public-key-only) half of the `self-signed-ec.pem` key pair | Public-key-only import/verify (no cert, no private key) |

## Regenerate

Everything here is produced by a small, throwaway Rust program — not a permanent dependency of any
shipping crate. To recreate the generator and rerun it:

```bash
mkdir crypto-samples-gen && cd crypto-samples-gen
cargo init --name crypto-samples-gen
```

Replace the generated `Cargo.toml` with:

```toml
[package]
name = "crypto-samples-gen"
version = "0.1.0"
edition = "2021"
publish = false

[dependencies]
rcgen = { version = "0.14", features = ["crypto", "pem"] }
rsa = { version = "0.9", features = ["pem", "sha2"] }
rand = "0.8"
hmac = "0.12"
sha2 = "0.10"
base64 = "0.22"
serde_json = { version = "1", features = ["preserve_order"] }
x509-parser = "0.16"
```

Replace `src/main.rs` with the generator source below, then run it pointing at this folder:

```bash
cargo run --release -- /path/to/repo/samples/crypto
```

It prints a `OK ...` line for every file after re-decoding/re-parsing what it just wrote (JWTs are
base64url-decoded and, where signed, HMAC-reverified; every certificate and the CSR are re-parsed with
`x509-parser`), so a broken fixture fails the run instead of silently landing in the repo.

Notes on reproducibility: the JWTs are byte-for-byte reproducible (all claim timestamps are fixed
constants, not wall-clock `now()`). The certificates/keys are **not** guaranteed byte-identical between
runs — RSA/EC key generation uses fresh secure randomness each time by design (as it should for any real
key material, even throwaway demo keys) — but the *shape*, subjects, SANs, and validity windows are fully
deterministic and the regeneration process requires no manual steps and no `openssl`.

No `rcgen`/`rsa`/`hmac`/etc. dependency was added to any shipping crate (`crates/*`, `src-tauri`) for this
— the generator above is scratch-only and is not part of the workspace.

### Generator source (`src/main.rs`)

Uses `rcgen` (ring backend — no `aws_lc_rs`/cmake needed) for all certificate/CSR generation, the
pure-Rust `rsa` crate for RSA-2048 key generation (`ring` can sign RSA but not generate RSA keys), and
hand-rolled `base64url` + `hmac`/`sha2` for the JWTs (no JWT library).

```rust
//! THROWAWAY generator for `samples/crypto/` (CPE-1425). Not part of the workspace, not shipped.
//! Run once, commit the resulting files, discard this crate.

use std::fs;
use std::path::{Path, PathBuf};

use base64::{engine::general_purpose::URL_SAFE_NO_PAD, Engine as _};
use hmac::{Hmac, Mac};
use rcgen::{
    date_time_ymd, BasicConstraints, CertificateParams, DnType, IsCa, Issuer, KeyPair,
    PKCS_ECDSA_P256_SHA256, PKCS_RSA_SHA256,
};
use rsa::pkcs8::{EncodePrivateKey, LineEnding};
use rsa::RsaPrivateKey;
use serde_json::json;
use sha2::Sha256;
use x509_parser::prelude::FromDer;

type HmacSha256 = Hmac<Sha256>;

/// Demo-only HMAC secret. Never use this (or any secret checked into a public repo) for anything real.
const DEMO_SECRET: &[u8] = b"cpe-sample-hmac-secret-DO-NOT-USE-IN-PRODUCTION";

fn b64url(bytes: &[u8]) -> String {
    URL_SAFE_NO_PAD.encode(bytes)
}

/// Hand-crafted JWT: base64url(header) + "." + base64url(payload) + "." + base64url(HMAC-SHA256(...))
/// (or an empty third segment when `secret` is None, for the `alg:none` fixture).
fn build_jwt(header: &serde_json::Value, payload: &serde_json::Value, secret: Option<&[u8]>) -> String {
    let header_b64 = b64url(header.to_string().as_bytes());
    let payload_b64 = b64url(payload.to_string().as_bytes());
    let signing_input = format!("{header_b64}.{payload_b64}");
    let sig_b64 = match secret {
        Some(s) => {
            let mut mac = HmacSha256::new_from_slice(s).expect("hmac accepts any key length");
            mac.update(signing_input.as_bytes());
            b64url(&mac.finalize().into_bytes())
        }
        None => String::new(),
    };
    format!("{signing_input}.{sig_b64}")
}

/// Round-trip check: re-decode the token we just built and (for signed tokens) recompute the
/// HMAC to prove the file we're about to write is actually valid.
fn verify_jwt(token: &str, secret: Option<&[u8]>) {
    let parts: Vec<&str> = token.split('.').collect();
    assert_eq!(parts.len(), 3, "JWT must have exactly 3 dot-separated segments");
    let header_bytes = URL_SAFE_NO_PAD.decode(parts[0]).expect("header is valid base64url");
    let payload_bytes = URL_SAFE_NO_PAD.decode(parts[1]).expect("payload is valid base64url");
    let _: serde_json::Value = serde_json::from_slice(&header_bytes).expect("header is valid JSON");
    let _: serde_json::Value = serde_json::from_slice(&payload_bytes).expect("payload is valid JSON");
    match secret {
        Some(s) => {
            let sig_bytes = URL_SAFE_NO_PAD.decode(parts[2]).expect("signature is valid base64url");
            let mut mac = HmacSha256::new_from_slice(s).unwrap();
            mac.update(format!("{}.{}", parts[0], parts[1]).as_bytes());
            mac.verify_slice(&sig_bytes).expect("HMAC-SHA256 signature verifies");
        }
        None => assert!(parts[2].is_empty(), "alg:none must carry an empty signature segment"),
    }
    println!("  OK decodes + {} bytes", token.len());
}

fn gen_jwts(out: &Path) {
    println!("== JWTs ==");
    let header_hs256 = json!({"alg": "HS256", "typ": "JWT"});

    println!("hs256-valid.jwt");
    let valid_payload = json!({
        "sub": "1234567890",
        "name": "Ada Lovelace",
        "iss": "https://samples.cpe.local",
        "aud": "cpe-sample-app",
        "iat": 1_700_000_000i64,
        "exp": 2_000_000_000i64
    });
    let tok = build_jwt(&header_hs256, &valid_payload, Some(DEMO_SECRET));
    verify_jwt(&tok, Some(DEMO_SECRET));
    fs::write(out.join("hs256-valid.jwt"), &tok).unwrap();

    println!("expired.jwt");
    let expired_payload = json!({
        "sub": "1234567890",
        "name": "Ada Lovelace",
        "iss": "https://samples.cpe.local",
        "aud": "cpe-sample-app",
        "iat": 1_600_000_000i64,
        "exp": 1_600_003_600i64
    });
    let tok = build_jwt(&header_hs256, &expired_payload, Some(DEMO_SECRET));
    verify_jwt(&tok, Some(DEMO_SECRET));
    fs::write(out.join("expired.jwt"), &tok).unwrap();

    println!("alg-none.jwt");
    let header_none = json!({"alg": "none", "typ": "JWT"});
    let none_payload = json!({
        "sub": "0000000000",
        "name": "Unsigned Example",
        "iss": "https://samples.cpe.local",
        "aud": "cpe-sample-app",
        "iat": 1_700_000_000i64,
        "exp": 2_000_000_000i64
    });
    let tok = build_jwt(&header_none, &none_payload, None);
    verify_jwt(&tok, None);
    fs::write(out.join("alg-none.jwt"), &tok).unwrap();

    println!("rich-claims.jwt");
    let rich_payload = json!({
        "sub": "9999999999",
        "name": "Grace Hopper",
        "iss": "https://samples.cpe.local",
        "aud": ["cpe-sample-app", "cpe-sample-admin"],
        "iat": 1_700_000_000i64,
        "nbf": 1_700_000_000i64,
        "exp": 2_000_000_000i64,
        "roles": ["admin", "editor", "viewer"],
        "permissions": ["read", "write", "delete"],
        "profile": {
            "theme": "dark",
            "locale": "en-US",
            "notifications": {"email": true, "sms": false}
        },
        "https://cpe.local/claims/department": "Engineering",
        "https://cpe.local/claims/level": 7,
        "tags": ["sample", "rich-claims", "demo"],
        "active": true,
        "score": 98.6,
        "metadata": null
    });
    let tok = build_jwt(&header_hs256, &rich_payload, Some(DEMO_SECRET));
    verify_jwt(&tok, Some(DEMO_SECRET));
    fs::write(out.join("rich-claims.jwt"), &tok).unwrap();
}

fn verify_cert_der(der: &[u8], label: &str) {
    let (_, cert) = x509_parser::parse_x509_certificate(der).expect("x509-parser parses the DER we just built");
    println!(
        "  OK {label}: subject={} not_before={} not_after={}",
        cert.subject(),
        cert.validity().not_before,
        cert.validity().not_after
    );
}

fn gen_certs(out: &Path) {
    println!("== Certificates ==");

    // --- self-signed-rsa.pem / .key / cert.der (RSA-2048) ---
    // rcgen's default (ring) backend can *sign* with an RSA key but cannot *generate* one (RSA
    // keygen needs aws_lc_rs + cmake/nasm), so the key is generated with the pure-Rust `rsa`
    // crate and handed to rcgen for signing.
    println!("self-signed-rsa.pem + self-signed-rsa.key + cert.der");
    let mut rng = rand::thread_rng();
    let rsa_priv = RsaPrivateKey::new(&mut rng, 2048).expect("RSA-2048 keygen");
    let rsa_pkcs8_pem = rsa_priv
        .to_pkcs8_pem(LineEnding::LF)
        .expect("encode RSA key as PKCS#8 PEM")
        .to_string();
    fs::write(out.join("self-signed-rsa.key"), &rsa_pkcs8_pem).unwrap();

    let rsa_key = KeyPair::from_pkcs8_pem_and_sign_algo(&rsa_pkcs8_pem, &PKCS_RSA_SHA256)
        .expect("load RSA key into rcgen");
    let mut rsa_params = CertificateParams::new(vec![
        "sample-rsa.cpe.local".to_string(),
        "www.sample-rsa.cpe.local".to_string(),
    ])
    .unwrap();
    rsa_params.distinguished_name.push(DnType::CommonName, "sample-rsa.cpe.local");
    rsa_params.not_before = date_time_ymd(2026, 1, 1);
    rsa_params.not_after = date_time_ymd(2027, 1, 1);
    let rsa_cert = rsa_params.self_signed(&rsa_key).expect("self-sign RSA cert");
    fs::write(out.join("self-signed-rsa.pem"), rsa_cert.pem()).unwrap();
    fs::write(out.join("cert.der"), rsa_cert.der()).unwrap();
    verify_cert_der(rsa_cert.der(), "self-signed-rsa.pem / cert.der");

    // --- self-signed-ec.pem (P-256) + public-key.pem ---
    println!("self-signed-ec.pem + public-key.pem");
    let ec_key = KeyPair::generate_for(&PKCS_ECDSA_P256_SHA256).expect("EC P-256 keygen");
    let mut ec_params = CertificateParams::new(vec!["sample-ec.cpe.local".to_string()]).unwrap();
    ec_params.distinguished_name.push(DnType::CommonName, "sample-ec.cpe.local");
    ec_params.not_before = date_time_ymd(2026, 1, 1);
    ec_params.not_after = date_time_ymd(2027, 1, 1);
    let ec_cert = ec_params.self_signed(&ec_key).expect("self-sign EC cert");
    fs::write(out.join("self-signed-ec.pem"), ec_cert.pem()).unwrap();
    verify_cert_der(ec_cert.der(), "self-signed-ec.pem");

    // public-key.pem = the SubjectPublicKeyInfo half of the self-signed-ec.pem key pair.
    fs::write(out.join("public-key.pem"), ec_key.public_key_pem()).unwrap();
    println!("  OK public-key.pem ({} bytes)", ec_key.public_key_pem().len());

    // --- chain.pem: root CA -> intermediate CA -> leaf ---
    println!("chain.pem (leaf + intermediate + root)");
    let mut root_params = CertificateParams::new(Vec::<String>::new()).unwrap();
    root_params.distinguished_name.push(DnType::CommonName, "Sample Root CA");
    root_params.is_ca = IsCa::Ca(BasicConstraints::Unconstrained);
    root_params.not_before = date_time_ymd(2024, 1, 1);
    root_params.not_after = date_time_ymd(2034, 1, 1);
    let root_key = KeyPair::generate_for(&PKCS_ECDSA_P256_SHA256).unwrap();
    let root_cert = root_params.self_signed(&root_key).expect("self-sign root CA");
    let root_issuer = Issuer::new(root_params, root_key);

    let mut inter_params = CertificateParams::new(Vec::<String>::new()).unwrap();
    inter_params
        .distinguished_name
        .push(DnType::CommonName, "Sample Intermediate CA");
    inter_params.is_ca = IsCa::Ca(BasicConstraints::Constrained(0));
    inter_params.not_before = date_time_ymd(2024, 1, 1);
    inter_params.not_after = date_time_ymd(2030, 1, 1);
    let inter_key = KeyPair::generate_for(&PKCS_ECDSA_P256_SHA256).unwrap();
    let inter_cert = inter_params
        .signed_by(&inter_key, &root_issuer)
        .expect("sign intermediate with root");
    let inter_issuer = Issuer::new(inter_params, inter_key);

    let mut leaf_params = CertificateParams::new(vec!["chain-leaf.cpe.local".to_string()]).unwrap();
    leaf_params.distinguished_name.push(DnType::CommonName, "chain-leaf.cpe.local");
    leaf_params.not_before = date_time_ymd(2026, 1, 1);
    leaf_params.not_after = date_time_ymd(2027, 1, 1);
    let leaf_key = KeyPair::generate_for(&PKCS_ECDSA_P256_SHA256).unwrap();
    let leaf_cert = leaf_params
        .signed_by(&leaf_key, &inter_issuer)
        .expect("sign leaf with intermediate");

    verify_cert_der(leaf_cert.der(), "chain.pem [leaf]");
    verify_cert_der(inter_cert.der(), "chain.pem [intermediate]");
    verify_cert_der(root_cert.der(), "chain.pem [root]");
    let chain_pem = format!("{}{}{}", leaf_cert.pem(), inter_cert.pem(), root_cert.pem());
    fs::write(out.join("chain.pem"), chain_pem).unwrap();

    // --- expired.pem: validity window entirely in the past ---
    println!("expired.pem");
    let mut expired_params = CertificateParams::new(vec!["expired.cpe.local".to_string()]).unwrap();
    expired_params.distinguished_name.push(DnType::CommonName, "expired.cpe.local");
    expired_params.not_before = date_time_ymd(2020, 1, 1);
    expired_params.not_after = date_time_ymd(2021, 1, 1);
    let expired_key = KeyPair::generate_for(&PKCS_ECDSA_P256_SHA256).unwrap();
    let expired_cert = expired_params.self_signed(&expired_key).expect("self-sign expired cert");
    fs::write(out.join("expired.pem"), expired_cert.pem()).unwrap();
    verify_cert_der(expired_cert.der(), "expired.pem");

    // --- request.csr: PKCS#10 CSR ---
    println!("request.csr");
    let mut csr_params = CertificateParams::new(vec!["csr.sample.cpe.local".to_string()]).unwrap();
    csr_params.distinguished_name.push(DnType::CommonName, "csr.sample.cpe.local");
    let csr_key = KeyPair::generate_for(&PKCS_ECDSA_P256_SHA256).unwrap();
    let csr = csr_params.serialize_request(&csr_key).expect("serialize CSR");
    fs::write(out.join("request.csr"), csr.pem().expect("CSR PEM")).unwrap();
    let (_, csr_parsed) = x509_parser::certification_request::X509CertificationRequest::from_der(csr.der())
        .expect("x509-parser parses the CSR we just built");
    println!("  OK request.csr parses: subject={}", csr_parsed.certification_request_info.subject);
}

fn main() {
    let out = PathBuf::from(
        std::env::args()
            .nth(1)
            .expect("usage: crypto-samples-gen <output-dir>"),
    );
    fs::create_dir_all(&out).expect("create output dir");

    gen_jwts(&out);
    gen_certs(&out);

    println!("\nAll files written + verified under {}", out.display());
}
```

## Verification performed at generation time

The generator itself asserts every file it writes before moving on (see `verify_jwt` /
`verify_cert_der` / the CSR check above), so a broken fixture would have failed the run rather than
landing in the repo:

- **JWTs** — each token's header and payload segments are base64url-decoded and parsed as JSON; the
  three HS256 tokens additionally have their signature recomputed and verified with `Mac::verify_slice`;
  `alg-none.jwt` is asserted to carry an empty third segment.
- **Certificates** (`self-signed-rsa.pem`, `self-signed-ec.pem`, `cert.der`, the 3 certs inside
  `chain.pem`, `expired.pem`) — each is re-parsed from its DER bytes with `x509_parser::parse_x509_certificate`,
  confirming a well-formed X.509 structure with the expected subject and validity window.
- **`request.csr`** — re-parsed with `x509_parser::certification_request::X509CertificationRequest::from_der`.
- **`self-signed-rsa.key`** — round-tripped through `rsa::pkcs8::EncodePrivateKey` and successfully
  reloaded by `rcgen::KeyPair::from_pkcs8_pem_and_sign_algo` to produce `self-signed-rsa.pem`, so the key
  and certificate are proven to match.
