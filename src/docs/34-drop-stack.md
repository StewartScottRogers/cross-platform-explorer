# Drop Stack

A persistent "shelf" you accumulate files and folders on while browsing — Path Finder's Drop Stack.
Pick items up while looking at one folder, navigate elsewhere, pick up more, and everything you've
shelved stays put in one place across folder navigations, ready to move or copy together in a later
step.

This page covers the panel: seeing what's shelved, removing an item, and clearing the stack.

## Opening the panel

A small **Drop Stack** handle sits fixed in the bottom-left corner of the window. It shows a count
badge once something is on the stack. Click it to open or close the panel — the panel itself is
off by default and opt-in, so it has no effect on the plain explorer until you use it.

## The list

Each shelved item shows as a pill with its filename; hover (or check the title tooltip) for the full
source path. Pills wrap onto more rows as the stack grows rather than shrinking or overflowing, and a
very long path is truncated with an ellipsis rather than breaking the pill's shape.

- **Remove one item** — click the small **×** on its pill.
- **Clear all** — the header's **Clear all** button empties the whole stack in one step.

When nothing is shelved yet, the panel shows a plain hint: *"Drop Stack is empty — right-click a
file → Add to Drop Stack."*

## Honest limits

This first cut is the shelf + list only — adding items via the context menu, and acting on the whole
stack at once (Move all / Copy all), land in follow-up tickets under the same Drop Stack epic.
