# Keyboard shortcuts

Settings has a **Keyboard shortcuts** section where you can see every built-in action and the
shortcut it's currently bound to, in one searchable list.

## Opening the viewer

Open **Settings → Keyboard shortcuts → Customize shortcuts…**. A dialog lists every action —
navigation, tabs, selection, file actions, view, and general — grouped the same way as the
quick "?" shortcuts cheat sheet, with each row showing the action and its current chord. An
action with no shortcut assigned shows **Unbound**.

## Searching

Type into the filter box at the top to narrow the list. It matches against both the action's
name (e.g. "rename", "new tab") and its group (e.g. "navigation", "selection"), so you can
either look up one specific action or browse a whole category.

## Read-only for now

This viewer is read-only — it shows you every shortcut, but you can't change one here yet.
Rebinding a shortcut from this same dialog is coming in a follow-up release; nothing about how
the app's shortcuts behave changes today. In the meantime, the quick "?" cheat sheet remains the
fastest reference while you're working.
