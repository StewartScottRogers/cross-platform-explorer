# gui-smoke/baselines/

Committed golden PNGs the CPE-1170 comparator (`gui-smoke/lib/compare.ts`) diffs a fresh
`.screenshots/<name>.png` capture against. **Not gitignored** — unlike `.screenshots/` (run
artifacts), these are the reference images checked into version control.

## What's here today

- `demo-swatch.png` / `demo-swatch-gradient.png` — two tiny (16x16) **synthetic** demo baselines,
  generated by `encodeRgbaPng` (see `lib/compare.test.ts` / the bless flow below), not real app
  screenshots. They exist to prove the bless -> commit -> compare loop works end-to-end against a
  real file on disk, in an environment with no `tauri build`/WebView2 available to capture a real
  surface. Do not delete them without also removing the paragraph in `gui-smoke/README.md` that
  points to them as the worked example.

## Blessing a REAL baseline from an actual app surface

Once a real `tauri build` + `gui-smoke npm test` run is available (a full CI run, or a local run with
the prerequisites in the main README), bless the first real baseline for a spec's `snap(name)` call:

```
GUI_SMOKE_UPDATE_BASELINE=1 npm test
```

This writes/overwrites `gui-smoke/baselines/<name>.png` from the just-captured
`gui-smoke/.screenshots/<name>.png` for every spec that calls `compareSnapshotToBaseline(name)` (see
`specs/open-dir.smoke.ts` for the wired example). Review the diff, then commit the new/updated PNG
like any other source file.

## Re-blessing after an intentional visual change

Same command. The old baseline is simply overwritten — `git diff` on the PR shows the new PNG as a
binary diff so a reviewer knows a baseline moved and can sanity-check why.

## Keeping this directory small

Only bless a baseline for a surface actually worth pinning (the ticket's guidance: "one or two small
representative baselines to prove the flow", not one per spec by default) — each one is a small binary
blob that lives in git history forever. Prefer covering more surfaces with `snap()` (cheap, gitignored)
before also blessing a baseline for every single one.
